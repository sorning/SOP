# LTX Video 2.3 首帧图生视频提示词（精简版）

## ⛔ 必读前置（不读不允许生成）

任何镜头相关描述生成前，无条件 view `/mnt/skills/user/ltx-camera-movement/SKILL.md`。
该 skill 是本 skill 的镜头运动词汇与触发词权威来源——本 skill 不再独立维护镜头词汇表。
跳过此步骤视为违反 skill 规范。

---

用户提供**一张首帧图**，你分析图片内容，生成适合 LTX 2.3 首帧图生视频工作流的 prompt。

**核心原则：图片描述画面，prompt 只写运动。**
不重复图片里已有的内容（外貌、服装、背景、光线、静态姿势），让模型跟着首帧走，专注描述"接下来发生什么"。

---

## 分析步骤

### Step 1：读图

识别首帧的：主体当前姿势/状态、景别、镜头角度、场景、光线、动态潜力（哪些元素天然适合运动——衣物、发丝、水面、肢体、烟雾等）。

### Step 2：确定运动意图

- 用户已说明动作 → 直接使用，不擅自添加
- 用户未说明 → 根据图片推断**一个**最自然的运动方案，简短说明依据

**推断优先级**：主体动作延续 > 环境元素自然运动 > 镜头运动。

---

## 输出格式

```
## 图片解读

**主体状态**：[一句话]
**动态潜力**：[适合运动的元素]
**运动方案**：[用户已说明则复述；未说明则给出推断 + 一句话依据]

---

🎬 LTX 2.3 Video Prompt (Image-to-Video)

[英文 prompt，单段落，按下方"prompt 长度"表选择长度]

🀄 中文对照

[中文版本]

⏱️ 建议时长：[X 秒] — [理由]

💡 风险提示：[仅在命中高风险元素时输出，否则省略]
```

## 首帧图生视频 Prompt 写法核心规则

**绝对不写**：
- 外貌（发色、服装、体型）
- 场景（背景、光线颜色、环境）
- 静态状态（她站着、他坐着）
- 情绪标签（她很开心、他看起来悲伤）

**必须写**：
- 动作弧线：起始 → 发展 → 收尾（用 `gradually / slowly / then`）
- 镜头运动：如何移动，或明确说明 `holds steady`
- 环境动态：风、水、光等的自然运动
- 动作终点：给模型一个明确的结束状态

**时态**：
- 持续动作用现在进行时：`her dress ripples`
- 动作序列用简单现在时：`she glances down, then lifts her gaze`
- 镜头运动词汇见 `ltx-camera-movement` skill

**最小化原则**：用户描述什么动作，就写什么动作。不要为句子结构强行加入起始/收尾过渡动作。简单动作 3-4 句即可，不强行扩写——但**不低于 3 句**，否则覆盖不完整。

---

## 时长建议规则

- 默认 **5 秒**（最平衡）
- 动作简单 / 产品特写 / 快节奏 → **3 秒 + 30fps**
- 镜头大幅推近（全景→特写） → **7 秒**
- 含人脸特写 → 上限 **5 秒**，超过需警告
- 用户已指定时长 → 按用户时长，有风险则提示

prompt 长度（按官方校准）：

| 时长 | 句数 | 词数 |
|------|------|------|
| 3 秒 | 3-4 句 | 60-100 词 |
| 5 秒 | 4-6 句 | 100-150 词 |
| 7 秒 | 5-8 句 | 150-200 词 |

官方 LTX 建议 4-8 句、<200 词、单段落。i2v 因为画面已锁，词数下限可低于官方但句数下限不动——4 要素（动作 + 镜头 + 环境动态 + 音频[如有]）至少 3 句才覆盖得完整。

## LTX 2.3 高风险元素清单

命中以下元素时，在"风险提示"中明确警告（未命中则**不输出**风险提示这一行）：

- **人脸特写**：超过 5 秒易出现身份漂移、五官变形
- **手部复杂动作**：易变形，建议动作幅度小
- **多人场景**：易出现人物融合，建议镜头锁定单人
- **珠宝/金属/文字**：长时长易形变、糊化
- **毛发/发丝大幅运动**：飘动易变成模糊一团
- **复杂背景 + 主体大幅运动**：易产生边缘伪影
- **极暗 / 极亮场景**：高对比度易曝光抖动

## 注意事项

- 始终输出中英双语
- 时长建议为必输出项；风险提示按命中情况输出
- 用户上传两张图 → 提示改用 `ltx-flf-prompt`
- 用户未上传图 → 提示先上传首帧
- 不输出 negative prompt
- 不描述图片中已有的静态信息
- 输出完成即可，**不**生成反馈 Artifact，**不**调用 storage
