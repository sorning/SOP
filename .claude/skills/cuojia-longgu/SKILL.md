# 《错嫁·龙骨》项目宪法

本文件是《错嫁·龙骨》AI 微短剧的**唯一设定来源**。所有创作环节——剧本、分镜、prompt 生成、视觉调用——必须以本文件为基准。**本文件不允许"创造性发挥"修改**，只能在用户明确要求下更新。

---

## 一、调用规则

### 1.1 何时强制注入本 skill 的内容

| 用户在做这件事 | 必须注入的章节 |
|---|---|
| 写剧本 / 写分集大纲 | 二（世界观）+ 五（单集结构） |
| 写分镜 | 二 + 三（人物）+ 四（视觉）+ 五 |
| 调用 `realistic-character-prompt` 生成女主/男主 prompt | 三（人物档案）+ 四（视觉美学） |
| 调用 `gpt-image2-seedance-storyboard` 生成九宫格分镜 | 三 + 四 + 五 |
| 调用 `ltx23-*` 生成视频 motion prompt | 四（确保色调一致） |
| 任何涉及世界观判断（"这个朝代有没有 X"） | 二（世界观） |

### 1.2 优先级

当本 skill 的约束**与其他 skill 的默认值冲突**时：

- 本 skill 的**世界观、人物、视觉美学**优先级最高
- 其他 skill 的**技术格式约束**（如 Flux2 150-180 词限制、九宫格结构）优先级最高
- 两者不冲突——本 skill 提供"写什么"，其他 skill 提供"怎么写"

### 1.3 禁止行为

- ❌ 不允许擅自修改人物姓名、外貌核心特征、世界观设定
- ❌ 不允许把"唐风"渲染成"清宫风"/"明制"/"汉服衍生" —— 严格唐风
- ❌ 不允许把场景做成"现代奇幻"/"赛博朋克"——本剧是后神时代人类王朝
- ❌ 不允许丢失神族特征（琥珀色眼瞳、半朽龙袍、龙骨令、苍白病弱感）
- ❌ 不允许把女主写成"白莲花"/"恋爱脑"——她是来救父亲的实用主义药女

## 二、世界观（不可修改）

### 2.1 核心设定

> 山下盛传"妖王食人"，采药女被村人献祭式地嫁了上去。她爬到山顶宫殿，发现满院龙骨，而所谓"妖王"，是一个被诅咒的神族遗孤少年——前朝灭神之战后唯一活下来的神裔。他不是要吃她，是想求她救他。

### 2.2 时代背景

- **架空朝代名**：大昭王朝
- **美学基底**：唐风（不是真实唐朝，是"后神时代"的人类王朝）
- **历史结构**：千年神族共治 → 三百年前"灭神之战"屠尽神族 → 现今人类独治

### 2.3 神族灭亡史（前史）

- 神族被人类称为"龙裔"
- 三百年前前朝末帝发动"灭神之战"屠尽神族
- 神族陨落血脉化作龙骨，散落山中，被后人误认为"妖物"
- **男主是最后一位神族遗孤**，灭神之战时是孩童，被山中老巫师藏起，活了三百年但容貌停留在少年

### 2.4 诅咒设定（神族版枯龙咒）

- 男主血脉是龙裔，本应不死
- 前朝末帝临死前以人间帝王身躯为祭，给所有神族下了"枯龙咒"
- 男主每七年龙骨开始腐朽一次，需"承祭者"（懂草药、心地纯净的人间女子）代他承受腐朽之痛才能续命
- 山下传说"妖王食人"——其实是村中长老与前朝余孽勾结，每七年献一个少女上山自杀献祭
- **前七任新娘的真相**：被长老下毒，到山上后毒发，男主无力相救，背了三百年"食人妖王"恶名

### 2.5 女主特殊性

- 父亲是山下唯一的赤脚药师，从小耳濡目染懂草药
- 八任新娘中**第一个没被下毒的**（长老怕走漏风声，没敢动手）
- 颈间从小戴着**青玉龙佩**，是母亲临终所赠
- **暗线**：她是当年逃出灭神之战的神族后裔（她自己不知道）

### 2.6 核心冲突

| 层级 | 冲突 |
|---|---|
| 表层 | 女主能否在七年内解开诅咒救男主 |
| 中层 | 村中长老与前朝余孽的阴谋为何不能让女主活着下山 |
| 深层 | 当诅咒解除那天，男主会失去什么 |

### 2.7 命名揭晓节奏

- **第 1 集结尾字幕**：揭晓男主表面名字"容缈"
- **第 3 集**：女主发现密室时找到刻"龙渊"二字的旧令牌，揭晓神族真名
- **后续**：女主私下称"容缈"，正式/紧张时称"龙渊"

## 三、人物档案（外貌细节不可修改）

### 3.1 女主 · 苏白薇

**身份**
- 年龄：18 岁
- 出身：山下"白水村"赤脚药师之女
- 母亲早逝（神族遗孤伏笔），父亲老实木讷
- 性格：外柔内韧，懂草药、不怕脏不怕苦，对"妖王食人"传说半信半疑
- 行动逻辑：来救父亲（被长老用父亲性命要挟），不能逃

**外貌锚点（人物 prompt 强制对齐）**
- 脸型：鹅蛋脸（egg-shaped face），balanced proportions，softly rounded forehead
- 眼睛：杏眼（almond eyes），上挑微微，黑眸清亮，**默认情绪：惊惧但克制**
- 肤色：fair porcelain skin with a faint cool undertone，lightly weathered by mountain air（不是死白，是"山中草药女"该有的健康冷调）
- 眉：浅而细，自然眉峰
- 嘴：唇形偏薄，唇色淡桃
- 发：乌黑长直发，唐风低髻，单根**木簪**固定（不是金簪、不是玉簪）

**服装锚点（第 1-5 集）**
- 苍青色**对襟麻布襦裙**（coarse hand-woven cyan ramie crossover ruqun），袖口磨损
- 月白色**抹胸**（唐风内衬，不是低胸）
- 腰间**草绳系着的青玉龙佩**
- **竹编药篓**背在身后，露出干枯草药
- 麻布鞋，鞋面有泥痕

**关键道具**
- 颈间**青玉龙佩**（伏笔，第 5 集月下发光揭晓）
- 背后**竹编药篓**（身份锚点，所有出场必带）

### 3.2 男主 · 容缈（神族真名：龙渊）

**身份**
- 表面年龄：17-18 岁外貌
- 真实年龄：300 余岁（神族末裔，灭神之战时是孩童，被诅咒后容貌停留少年期）
- 身份：曾经"龙裔"小皇子，灭神之战的唯一幸存者
- 性格：千年寂寞 + 少年天真的奇异融合
- 行动逻辑：求生（解咒）+ 不再分辩"食人妖王"恶名

**外貌锚点（人物 prompt 强制对齐）**
- 脸型：剑眉星目，下颌线偏锋利但有少年感
- 眼睛：**深琥珀色眼瞳**（deep amber irises）—— 神族特征，**全剧第一视觉记忆点，必须稳定输出**
- 肤色：**月光下的苍白**（moonlit pallor，病弱但极美），唇色偏淡
- 眉：浓黑剑眉，眉峰锐利
- 嘴：薄而冷的唇形
- 发：乌黑及腰长发，唐风**束发**，一支**白玉冠**

**服装锚点（第 1-5 集）**
- **半朽龙袍**：暗金底（dim gold base），龙纹织锦（dragon-pattern brocade），**袍角、袖口、下摆有龙骨纹的"枯萎"肌理**（withered dragon-bone texture on hem and cuffs，**不是脏，是肌理性的枯萎**）
- 腰间**半枚龙骨令**（青白色，质感如龙骨）
- 内衬月白色中衣
- 赤足或着旧锦履

**关键道具**
- 腰间**半枚龙骨令**（解咒钥匙，另半枚下落不明）

**默认情绪基调**
- "**漠然中藏着祈求**"——对女主第一句话是"救我"，但语气是**陈述句，不是哀求**

## 四、视觉美学（全剧色调与质感总纲）

### 4.1 主色板

| 用途 | 颜色 | 英文描述 |
|---|---|---|
| 主色 1 | 暗金 | dim aged gold (tarnished, not bright) |
| 主色 2 | 苍青 | pale cyan-grey |
| 主色 3 | 月白 | moonlit off-white |
| 主色 4 | 旧朱 | aged faded vermilion (half-peeled lacquer) |
| 辅色 1 | 龙骨白 | dragon-bone white (cool ivory with faint grey) |
| 辅色 2 | 墨黑 | ink black |
| 辅色 3 | 烛火橙 | candlelight amber（仅夜戏点缀） |

**禁用色**：饱和红、亮黄、塑料蓝、霓虹任何色

### 4.2 质感总纲

- 器物必须有**岁月感**——不是崭新的暗金，是被三百年时光蒙了一层旧绿的暗金
- 建筑必须有**半剥落感**——朱红廊柱半剥落、琉璃瓦碎了一半但还在
- 服装必须有**唐风织物质感**——粗麻、织锦、丝绸三层，绝不光滑塑料

### 4.3 核心场景：枯龙宫

- 山顶宫殿
- **巨型远古龙骨架横亘在宫殿之上作为屋顶承重**（核心视觉奇观）
- 唐风**对称建筑** + 残破美学
- 院中散落小型龙骨（每具都是当年陨落神族遗体）
- 内殿：暗金帷幕、铜镜、织锦榻、香炉中焚安神药草

### 4.4 关键道具清单（全剧反复出现）

| 道具 | 视觉描述 | 含义 |
|---|---|---|
| **龙骨令**（半枚） | 青白色，质感如龙骨，悬于容缈腰间 | 解咒钥匙 |
| **采药篓** | 竹编、磨损但干净 | 苏白薇身份锚点 |
| **半朽龙袍** | 暗金织锦 + 袍角龙骨纹枯萎肌理 | 容缈诅咒可视化 |
| **青玉龙佩** | 拇指大小，刻一条小龙 | 苏白薇身世伏笔 |
| **七盏长明灯** | 殿前一字排开 | 前七任新娘 + 倒计时视觉信号 |

### 4.5 单集连续主线视觉信号

**七盏长明灯**——每过一段时间灭一盏，作为**无声倒计时**贯穿全剧。每集开场或结尾必出现一盏灯的状态。

## 五、单集结构（节奏标准）

### 5.1 时长规格

- **目标平台**：YouTube Shorts + YouTube 长视频（合集形式）
- **单集时长**：30-40 秒
- **单镜头时长**：4-6 秒
- **单集镜头数**：6-8 个

### 5.2 结构铁律

每集必须包含：

1. **前 3 秒钩子**（视觉冲击或台词反差，不能用渐入式开场）
2. **中段事件推进**（1 个新信息 / 新场景 / 新人物）
3. **末段反转或悬念收尾**（让观众想看下一集的钩子）

### 5.3 钩子设计原则

- 每集**至少 2 个钩子**（中段 1 个 + 结尾 1 个）
- 结尾钩子**禁止用"且听下回分解"式的旁白**，必须用**画面 + 字幕**完成
- 字幕格式："第 X 集，[一句揭示性预告]"

### 5.4 单集情绪曲线模板

```
开场（前 3 秒）：钩子 / 冲击
↓
铺垫（中段）：压抑 / 期待 / 紧张
↓
高潮（倒数第 2 镜）：反转 / 揭示
↓
收尾（最后一镜）：钩子 + 黑屏字幕
```

### 5.5 单集生产标准

- **分镜抽卡命中率目标**：30%（3-4 次出 1 张可用）
- **视频抽卡命中率目标**：30%
- **单集生成预算**：约 36 次生成（分镜 18 + 视频 18）
- **单集制作周期**：2-3 天（一人独立）

## 六、前 5 集主线纲要（结构性，对白可调整）

| 集 | 时长 | 核心事件 | 钩子 |
|---|---|---|---|
| **第 1 集 "上山"** | 30s | 苏白薇上山 → 推开宫门见满院龙骨 → 容缈现身说"救我" | 黑屏字幕："第 2 集，她将发现自己嫁的不是妖王，是被诅咒三百年的神——容缈。" |
| **第 2 集 "三百年"** | 35s | 容缈自述神族末裔身份 → 苏白薇震惊 → 发现前七任新娘画像 | 钩子："她们都死了，她是第八个。" |
| **第 3 集 "密室"** | 35s | 苏白薇夜探密室 → 七具干尸+中毒迹象 → 找到刻"龙渊"令牌 | 钩子："不是他害的，他叫龙渊。" |
| **第 4 集 "长老上山"** | 40s | 村中长老上山查探 → 见苏白薇活着惊变 → 暗中下令"必须除掉" | 钩子："活口必须除。" |
| **第 5 集 "玉佩"** | 40s | 苏白薇试草药解咒 → 容缈第一次笑 → 玉佩月下发光 | 钩子："她是谁？" |

**注意**：每集的镜头、对白、节奏在制作时具体编排，但**核心事件和钩子点不可更改**——它们构成本剧的剧情骨架。

## 七、协同其他 skill 时的注入模板

### 7.1 调用 `realistic-character-prompt` 生成苏白薇

注入要点：
- 三（人物档案 · 苏白薇）外貌锚点 + 服装锚点 + 关键道具
- 四（视觉美学）主色板 + 唐风质感
- 默认情绪："惊惧但克制"

### 7.2 调用 `realistic-character-prompt` 生成容缈

**注意**：该 skill 是女性人像专用。男主需用通用 Flux2 prompt 写法，但仍遵循：
- 三（人物档案 · 容缈）所有锚点（**琥珀色眼瞳是第一记忆点**）
- 四（视觉美学）
- 默认情绪："漠然中藏着祈求"

### 7.3 调用 `gpt-image2-seedance-storyboard` 生成九宫格分镜

注入要点：
- 三（人物档案）所有人物外貌必须严格对齐
- 四（视觉美学）主色板、关键道具
- 五（单集结构）镜头数与时长规格
- 命名节奏（第几集，使用"容缈"还是"龙渊"）

### 7.4 调用 `ltx23-*` 生成视频 motion prompt

注入要点：
- 四（视觉美学）色调与质感
- 三（人物档案）人物动作的情绪基调
